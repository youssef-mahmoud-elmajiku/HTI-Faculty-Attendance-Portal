# HTI Faculty Attendance & Student Academic Portal

A faculty attendance and student portal project concept.

## Project scope

The portfolio describes mobile attendance flows using GPS geofencing and rotating QR codes, backed by a PHP REST API.

## Technologies listed in the portfolio

- Flutter 3 and Dart
- PHP REST API
- GPS geofencing
- Rotating QR codes

## Status

This repository currently contains project documentation only. Source code, deployment details, and attendance-validation results are not included.
